# 分时竞价、叠加、动态预警及条件推演

分时固定为北京时间09:30–11:30、13:00–15:00，午休压缩，尚未成交的时间保持空白。主线与VOL共用时间轴。大盘、板块可以分别选择叠加，以各自昨收归一后的涨跌幅比较，仅合并同交易日，不向缺失分钟填充假价格。

竞价在分时内展开，分开显示09:15–09:25开盘集合竞价、14:57–15:00收盘集合竞价和15:05–15:30盘后固定价成交。东方财富公开时间序列优先，保留源时间与逻辑时间（最终开盘撮合量额可能写在09:26行，不能拿09:31连续成交代替）。来源失败时核验腾讯第一分笔页的09:25撮合；尾页盘后成交仅称样本，不冒充全量。普通收盘分钟记录称“分钟观测”，不冒充虚拟参考价、撤单或未匹配量。

板块优先用公开板块指数分时；失败后至多拉取6只成分样本，至少3只同交易日、各分钟至少70%覆盖才构成等权参考。如果成分来源发生分类降级，标签显示实际分类名和“相关分类样本”，提示不是原板块指数。只在打开叠加后取数，板块60秒复用，不进行全市场轮询。

盘中可撤销的形态和买卖预警从主图标注分离为`liveAlerts`，展示在行情摘要／当日走势分析。策略判断和风控依据保留；收盘后满足条件的形态回到历史图表，不把盘中观察当确认成交。指标副图标注仍有独立开关。

推演从当前周期最后一根有效K线出发，支持日／周／月及5、15、30、60、120分钟K，各向后推演5、10、15、20根，日K默认10根（约两周），也可选四周。当前MA位置、斜率、5/20根动量、ATR、突破位置、实体／影线、量比与路径效率参与匹配，排除相反趋势的低质量邻居。至少4段不重叠同股样本时，选一条整段加权代表路径，按当前ATR、近5根量能缩放OHLCV；不再逐日拼接中位数。否则保留近30根实际量价片段，以3根为块做有界、可重复的重采样并保留适度当前动量。偏强／偏弱按期末收益排序，途中可以交叉，不能把三条路径解释为每日价格上下界。盘中未完成日／周／月量按已过交易时段估计，避免将半日成交量当作全天缩量。A股日K假设价格按代码板块限制并对齐分币；ST仅在提供名称时识别，上市初期等特殊规则未覆盖，不能当成可成交报价。

验证记录：使用用户示例之外的12只股票、204段滚动前缀，10根108段、20根96段。10根期末收益绝对误差均值8.05个百分点， unchanged-price基线7.19、旧算法7.28；20根误差12.44，基线10.95。新模型没有证明方向或期末价格预测优于基线，不能宣称高胜率；改善的是整段量价形状、依据可追溯和假设指标连贯性。参数未用这些回放结果调优。原始来源与逐段结果保存在本次交付的 outputs/projection-v2/rolling-validation.json（不提交大份行情样本）。
当前启用的自定义MA、BOLL、SAR及VOL／MACD／KDJ／RSI基于“真实历史＋所选假设K线”继续计算，推演区使用虚线及较低透明度；原始行情、形态判断、评分、买卖点仍只使用真实前缀。推演区可查看假设OHLC，切换情景不会改写历史。分位不是上涨概率或置信区间，尚未证明收益可预测性。显示支撑、压力和各分支条件。日期按相应周期与时段排版，分钟跳过午休、收盘和周末，周／月使用相应周期末，未含节假日，不声称为交易所开市日历。iOS沿用本机JavaScriptCore后台队列，开启后随最新量价、MA重新计算，不增加Worker量化重算负载。

验证覆盖固定时轴、竞价虚拟／成交量额分离、不引用未来样本、推演分支有序与原数据不变、盘中预警可撤销及收盘确认；Flutter验证展开竞价、选择叠加、同日基准和完整绘图。原生集成测试额外调用实际JavaScriptCore推演入口并保存分时／竞价截图。

分时固定时轴使用完整交易日锚点，禁用右边界向已成交最后一分钟自动吸附；未来空白留在右侧。VOL按与上一成交分钟的价格比较标红绿。分时MACD(12,26,9)仅以已成交一分钟价格更新，33个有效分钟预热，跳过午休与缺失分钟。个股默认叠加对应市场指数，可关闭或改选。

指数白线为公开实际指数；黄线目前是来源成分名单页内分散抽取至多6只的样本等权涨跌参考，显示样本数、覆盖要求与非全成分的说明，不把成交均价冒充不加权指数。它与券商全成分黄线有差异，正式全成分源仍未取得；来源不足3只或覆盖不足80%的分钟不画。

选股雷达保留最近收盘结构评分与日期，独立批量校验当前显示候选（最多60只）的实时价、涨跌色、量比及结构防守位。只在前台刷新候选报价，不触发全市场量化扫描。缩量下跌不自动淘汰，放量走弱／失守防守位单独标记；缺失／过期报价不能视为买点确认。除权或历史防守位无法对齐时不直接比较。

手机自选支持多张截图（iOS PhotosUI＋Vision本机识别）、粘贴名单、TXT／CSV／JSON文件。识别后核验代码、预览名称、勾选分组并合并，保留已有自选和分组；图片不上传，代码用于查询名称。最多20张图、2MB文本，当前自选容量60只。其他App的专有二进制格式和仅有名称无代码的截图不能直接承诺识别。参考：[Apple Vision](https://developer.apple.com/documentation/vision/recognizing-text-in-images)、[PhotosUI](https://developer.apple.com/documentation/photosui/phpickerviewcontroller)、[时间序列滚动检验](https://otexts.com/fpp3/tscv.html)。
