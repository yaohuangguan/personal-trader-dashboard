# 资金流与拆单观察

个股工作台默认进入「K线」。关联标签位于图表上方；资金流、板块、F10 等无需先滚过整张图表。切换标签保留 K 线的视区。

## 数据与来源

- 东方财富盘中资金估算优先，失败后尝试日度源；显示实际返回的交易日期与分类，缺失单档不填零。
- 新浪独立日度源读取最近 60 个交易日。`r0_net` 是来源的主力净额，`netamount` 是全部净额，`r0_ratio × 100` 为主力净额占比。两者分开展示，不能互相替代。1/5/10/20 日累计只在同源、有效数据覆盖完整时计算。
- [新浪来源定义](https://finance.sina.com.cn/temp/guest4377.shtml)：资金流是根据行情成交方向及单额统计的估算。来源中的「主力」是分类名称，不能用于确认机构账户或真实持仓。不同供应商分类不得拼接累计。
- 腾讯公开约 3 秒聚合分笔按需读取最近 6 页，不是全日数据或原始订单。页面显示实际样本日期、时间、条数、方向覆盖；只有与快照同日且金额相容时才显示成交额覆盖率。集合竞价、尾盘集合竞价剔除。

## 拆单与承接估算

「暗盘／拆单特征观察」不是暗盘实际资金净额。它提供以下可核验线索：

1. 样本内主动买、主动卖和中性成交，按聚合成交金额分类；与供应商全日资金统计分别展示。
2. 连续同向小额成交候选：至少 5 条、相邻间隔 ≤6 秒、30 秒内、每条 ≤20 万元、合计 ≥30 万元、量的变异系数 ≤0.35、价格偏离 ≤0.3%。候选组不重复计数。
3. 主动买额占已识别额 ≥60% 而价格推进 ≤0.15%，提示卖方抛压／承接；主动买额占比 ≤40% 而价格变化 ≥−0.15%，提示买方承接。与价格同向增强另行标识。判断要求至少 40 条、累计有效间隔 ≥5 分钟、方向覆盖 ≥80%，午休长间隔不计。

这些是公开样本的研究阈值，未经收益率校准，不输出虚构的「主力拆单净额」或确定性吸筹／派发结论。公开聚合分笔缺少账户、原始委托及成交关联，无法证明同一主力在拆单。[上交所 Level-2 产品说明](https://www.sseinfo.com/services/assortment/level2/)列出了更完整的订单、成交及关联信息；既有授权适配层继续保留。

## 板块来源

东方财富板块成分失败后，可显示明确命名的新浪相关分类参考，不冒充原板块成分。新浪概念下拉入口可直接读取机器人、创新药等概念真实成分。分类代码、来源和缺失的主力净额分别保留。

## PWA 更新

新版本外壳资源下载完成后才允许切换，显示已下载文件数与进度。检查、下载及切换都有超时反馈和重试；下载失败删除未完成的新缓存，保留旧外壳和自选／分组／设置。行情 API 不进入外壳缓存。多窗口通过控制器切换自动重新打开一次。旧域名保留同源升级资源，导航再迁移到 guanlan，避免跨域资源重定向导致安装失败。
