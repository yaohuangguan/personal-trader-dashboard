# 双向分级走势识别及样本外验证

本轮修正的是图表对**已经发生的走势状态**的表达，不宣称预测下一根涨跌，也不把状态确认日当成最低／最高点或新买点。单根放量上涨仍按一阳多线、突破、收复等原形态记录，不能单凭它宣布一段上涨行情必然开始。

## 状态及证据

短线默认 MA5/13，观察10根；波段默认 MA20/60，观察30根。斐波那契或自定义均线按实际启用参数映射角色，快慢周期不够区分时不给结论。两个级别可以方向相反。

上涨／下跌分别核验：价格相对快慢线的位置、均线方向、ATR归一化的净推进、路径效率、回归一致性、近5根涨／跌成交量参与，以及连续2／3根证据。v2.1还要求确认当根方向相同：上涨需上涨阳线且收在振幅上半区，下跌需下跌阴线且收在下半区；不在高开砸盘或低开反包当根新增相反结论。股性与买点风险空间继续由原交易计划判断，不因为银行弹性低就否认已存在的下跌。缩量阴跌也能形成下跌状态。

标注为「短线上涨确认」「短线下跌确认」「波段上涨确认」「波段下跌确认」。这些是当日已满足条件的状态确认，代替含混的「趋势开启」。已知摆点由右侧两根确认后才可用于下一根防线。单次失守先记本级转弱；持续失守、放量反向破位或推进效率显著下降才退回整理。原方向失效不等于反向确立，使用「本级上涨／下跌失效 · 整理」，避免一句「趋势结束」被理解成后面一定反转。正常回踩守住本级支撑可保留原状态。

盘中只标预警，价格和累计量改变后可以撤销；已确认的历史事件不因后面上涨／下跌被删除或挪回极值。上涨红、下跌绿、整理中性。底部最新状态区和手机标注依据区明确展示两个级别。

## 断头铡刀

原「死亡开花」规则保留。新增断头铡刀冻结前一日均线作比较：前序有中期支撑／反弹，长阴实体切断至少三条不同的快中期均线、失守中期线与前低、收近低位，并有参与量或显著实体幅度。无需强制包含60线，不再因当日重算均线移动门槛或未到1.5倍量漏掉明显长阴穿线。高开长阴只切两线时另标「高开低走 · 长阴破位」。已经持续阴跌、未切线的大阴线以及只有长下影的K线不能冒充断头铡刀。

新增风险形态进入原策略的风险证据集合；趋势状态本身不另造一套买卖点。保留旧的有效形态和交易条件，新增风险观察引起的变化单列核查。

## 验证协议

固定名单见 `tests/fixtures/trend-validation-universe.json`。在读取新版结果前选定40只行业不同的股票，排除用户截图案例及上一轮3只性能样本。按股票代码SHA256首字节奇偶分成16只开发组和24只保留组。腾讯／新浪公开前复权日线每只500根，截到2026-10-28，失败样本不按收益替换。本次40只均取得数据。

第一轮在合成序列及开发组检查后冻结v2规则SHA256，再运行24只保留组。随后发现部分确认日是反向实体，增加确认当根方向约束。因为已经看过第一轮结果，另行预先固定 `tests/fixtures/trend-confirmation-holdout.json` 中24只新股票作为最终保留组，在读取它们的历史前冻结v2.1。最终组检查后没有再按收益调整阈值。两轮共64只不同股票，每只500根、两套均线；合计640次历史截断检查，原有形态及已确认买卖信号在128组对比中保留。每组核验追加未来数据不会修改历史标注；盘中确认、相反周期和反向实体另有自动测试。

机器报告为 `docs/validation/trend-regime-2026-10-29.json`，包含分组、规则哈希、每个原始快照哈希、原形态保留数量、交易信号变化与历史截断检查。可复核脚本：

```powershell
node --import tsx tools/validate-trend-regimes.ts --data=完整快照目录 --baseline=a49cef4版本完整检出目录 --split=final-holdout
```

快照目录应包含每只 `symbol.json` 和下载时的 `manifest-results.json`；本次冻结快照保存于工作区 `outputs/full-market-mobile/regime-validation`。脚本只用事件之后的收益评估结果，未来收益从不进入识别输入。前250根用于指标和结构预热，后250根统计；两套MA及重叠事件有相关性，不能当独立交易样本。

**结果界限必须保留**：状态识别通过因果性／方向覆盖检查，不等于未来走势必然延续。最终24只保留组中，短线上涨／下跌确认后5根方向延续约50%／48.8%；波段上涨／下跌确认后20根约56%／35.6%。样本量分别132／242／25／59，并存在重叠及两套均线相关性。这些是未经交易成本、止损、涨跌停成交或组合约束的描述统计，既不是人工标注的识别准确率，也不是交易胜率；部分均值仍为负，不能据此声称存在稳定收益优势。下跌方向、震荡、分级和错误语义已修正，但「精准预知趋势」没有被这些样本证明，仍需继续积累独立的实时样本。第一轮的失败结果同样保留在JSON中，没有只展示好看的案例。
