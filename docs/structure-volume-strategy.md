# 结构量价 v2.0

金叉、死叉保留为均线参考，不再直接生成“买 / 卖”。图表买卖字样、个股计划、自选建议及新生成的选股报告使用同一结构量价策略。旧的指南评分仍按原规则显示；评分不是胜率。

## 决策和确认

- 环境：价格守住 MA60，60 日线近五根未明显下弯。采用最近 20 根高点、先前五线压缩及 ATR20 定义关键位，不借用未来数据。
- 启动：压缩后突破关键位，或阳线实体穿过至少三条核心均线且含 MA60。突破量至少为前20根均量1.5倍、中位量1.4倍，收盘在当日振幅上方30%。这是具体化参数，不声称是原指南给定阈值。
- 回踩：启动后2–10根内，缩量回踩守住关键位，再次突破前一根高点并有承接。回踩量与启动量、前一根量分别核验。
- 入场约束：必须处于关键位+0.05至0.85 ATR区间，结构风险不超过8%；低弹性、历史延续偏弱或上方阻力不足1.8R时不给出买入观察。选股仍统一要求成交额至少2亿元和筹码集中度底线；个股日线接口未独立取得当日成交额，不声称已经通过该项。
- 退出：先前生效的结构/ATR失效价、突破后5根内跌回关键位，或放量跌破前低并收近低点。移动失效价只在下一根生效，不能用当天高点倒算当天止损。
- 北京时间15:00前，当日仅为预警，不画已确认买卖点。收盘信号代表规则观察，并非实际成交或账户持仓。

## 历史检验

固定参数观察后30%时间窗口，信号后下一开盘仍在入场区间才模拟成交。采用A股T+1、单边综合成本15bp（假设值）、跳空止损按较差开盘价；同根触及止损/止盈先按止损，一字K保守不成交。入场当日触及失效价时，最早下一个可交易开盘退出。少于20笔完成交易不展示胜率。未模拟真实排队、停牌延期和持仓仓位优化，不是样本外实盘业绩，也未证明优于均线策略。

## 截图分享

iOS 个股右上角“分享当前画面”捕获当前可见页面，包含正在看的K线或分析栏目。PNG交给系统分享面板，可选择已安装并提供分享扩展的微信；不自动发送到联系人。行情详情提供“复制当前画面”，通过UIImage写入系统图片剪贴板，可在微信粘贴。应用不调用Photos保存、不申请相册权限；系统分享临时缓存不属于用户相册。

网页同样提供截图分享，按需加载 html2canvas。支持图片文件的浏览器走系统分享，否则显示截图预览和复制按钮。仅捕获当前可见视口，不上传图片；第三方嵌入视图受浏览器跨域限制，无法保证捕获其内部内容。
