# 五线量价研判 v3

结构准备度、当前买点分、已有持仓的退出风险分开显示。分数为规则证据评价，既不是上涨概率，也不是成交承诺。空仓与已有持仓分别给出条件建议，系统不假设用户真的持有模拟仓位。

一阳多线、箱体突破、跌破后的放量收复是独立启动路径；回踩后放量转强可以形成另一条路径。不要求每只股票经过相同的两次启动。一段计划失效后，保留原失效日期，新的量价证据可以建立新计划。

每次启动跟踪随后十根已收盘日线，记录相对启动量、相对前20日均量、五线离散及支撑状态。十日不是强制买入期限；较长整理仍可重新评估。箱体放量仅描述价格区间内的成交换手，不能证明机构吸筹。

核心五线为5/10/20/30/60，短线恢复另看5/13。原始指南的全部严格开花条件保留为独立检查项，不代替多路径量价研判。图表标记包括一阳多线、放量收复、局部高点突破、箱体放量、仙人指路候选、美人肩、金蜘蛛、多方炮、下跌后放量、回踩转强与结构失守。形态圆点与规则买卖箭头分别开关，MA交叉默认关闭。

入场需要主动承接、风险位置、趋势环境和股性支持。初始失效价参考启动实体半位与ATR；回踩转强参考已发生的回踩低点。高乖离降低新买入评价，但不自动要求已有持仓清仓；缩量失守支撑也触发风控。2R/3R是规则风险预算刻度，仅在入场区间有效时列示，不预测未来价格。

综合研判逐项显示日线结构、动能、已收盘周/月、指数快照、涨停生态、板块、公开资金估算和活跃程度。不同来源必须核验日期；缺失、无独立行情日期及历史资金记录明确标注，不补零加分。基础技术买入候选还需要市场证据及至少一种板块、资金或情绪联动，覆盖不足时维持技术候选。成交额至少2亿元、涨停无有效卖盘、行情未对齐等条件会限制新入场。

盘中日线不外推全天量，不计入已完成跟踪天数，也不生成确认买点。历史买卖标记只使用对应日期及以前的OHLCV，没有已保存的当时市场/板块/资金快照，因此不能冒充完整综合决策。规则卖出价仅供历史检验；实际交易还受T+1、滑点、停牌和涨跌停可成交性影响。

验证覆盖缩量回踩待承接、放量收复、支撑失效后再启动、趋势强但不追高、未收盘日、来源日期不符以及历史标记不被后来行情改写。实盘样本用于核验状态解释，不据此宣称胜率或按个别成功样本调参。

## 形态命名与显示

普通一阳多线至少阳线实体穿过四条指南核心线（5/10/20/30/60）。两三条穿线只按实际收复均线命名，底分型标在右侧确认日。强力一阳多线在上述基础上要求含MA60、线束离散<5%、线束中心距实体中点≤实体高度25%、涨幅>5%、收盘处于振幅上方10%、前20根相对量≥2、前5根相对量≥1.5、量超过此前三根最大量10%。这些是对用户形态描述的可执行参数；后续3–5根的半位支撑与多头排列仍单独跟踪，不把未来确认回填启动日。

仙人指路先要求上升初段、适度乖离、受控量和受控上影振幅；候选不在主图冒充确认。随后1–3根若支撑未失守、放量突破上影高点，才在实际确认日标注。高位射击之星、下跌中的倒锤头与它分开。美人肩、金蜘蛛、多方炮等同时收紧趋势、实体和量能约束。

覆盖清单由 `GUIDE_PATTERN_COVERAGE` 提供：均线中继、单根/组合K线、颈线结构、指标协同、量价与风险，以及周/月专项。摆点经过右侧两根才可识别，M/W与头肩形态标在颈线突破日。图上按空间显示最多六条重要形态文字，完整同日证据在固定高度的悬停说明区呈现；形态覆盖层不参与价格自动缩放。

## 盘中与收盘

取得同日15:00及以后的有效快照后，走势面板切换为收盘分析。盘后新消息只选交易日15:00以后且不晚于分析时间的带时间记录；收盘前消息单列。美股使用来源的纽约时间并转换UTC，显示最近可核验交易时段，不将前一晚美股冒充尚未发生的今晚行情。盘口仅分析可见五档挂单与价差，不将挂单占比当成主动资金流。
