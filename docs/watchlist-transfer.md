# 自选文件交换

网页版、PWA 和 Flutter iOS 使用同一份 JSON 文件交换股票与分组，不需要发送云同步密钥。

1. 在自选页或设置中点「导出自选」。手机使用系统分享，电脑下载 `guanlan-watchlist-日期.json`。
2. 将文件发送给另一位用户；对方在观澜点「导入自选／导入自选文件」，选择收到的文件。
3. 核对预览后点「一键合并导入」。iOS 可以取消部分股票或取消导入分组。

合并保留接收方已有股票、顺序和分组；同名分组追加成员，重复导入不会产生重复股票。最多新增到 60 只股票、20 个分组，超出项在预览中提示跳过，已有数据不会因此删除。旧版本已有更多自选时也会保留。

文件只包含股票代码、分组名称与成员，不包含账号、云同步密钥、提醒或本机分组标识。导入预览和保存不依赖行情源；保存后沿用设备现有的行情刷新与用户已开启的云同步。导入不会连接到发送方的同步空间。文件本身包含个人关注的股票，接收方可以转发。

## 格式

```json
{
  "format": "guanlan-watchlist",
  "version": 1,
  "watchlist": ["300031.SZ", "AAPL"],
  "groups": [{"name": "科技", "symbols": ["300031.SZ", "AAPL"]}]
}
```

兼容历史代码数组和 `{"watchlist":[...]}`。裸六位代码按沪深北规则补市场后缀，英文代码转大写。文件最大 256 KiB，最多 200 个代码条目、30 个分组；未知版本、非法代码或引用文件名单外股票的分组会拒绝导入。

校验覆盖共享格式跨端往返、凭据排除、重复导入、容量限制、浏览器存储失败回滚、Flutter 本地持久化、iOS 文件选择和系统文件分享。网页另用两个隔离的浏览器用户执行导出、导入和重复导入，在桌面、390px 手机、深浅主题和中英文下验证。
