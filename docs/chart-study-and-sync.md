# 形态量价 v4 与自选同步

图表 MA 支持经典 `5/13/20/30/60/120/144/250`、斐波那契 `5/13/21/34/55/89/144/233` 与自定义参数。标注使用当前启用的均线重新计算；55/60、34/30、144/120作为对应的决策周期。两套筛选分别计算，可选任一套、指定一套或两套均命中，不能把两套各穿几条拼成一次穿四线。

普通一阳多线必须阳线实体实际穿过至少四条选定均线，并满足线束密集、有效实体、量能与收盘位置。中轴居中不是普通形态的必要条件。强力另外要求55/60线、密集居中、显著增量与收近高点。`tests/fixtures/002472-20261020.json`是从生产来源保存的双环传动历史回归样本，核验经典5条与斐波那契6条；不把它当作策略收益验证。

买卖引擎与形态识别共用同一组 OHLCV 和 MA。形态触发后仍需量价承接、短线恢复、趋势环境、股性、可接受入场区间和风险空间。回踩、均线金叉、底背离均不能单独触发买入；风险形态与放量失守支撑共同提高退出风险。已持仓规则跟踪与空仓计划分别显示。缺少成交额核验时不声称已通过2亿元底线。历史箭头是本地量价规则观察，未加入未留存的当时板块、情绪、资金流，不能当作真实成交或收益保证。

MACD与KDJ在各自副图显示金叉/死叉和顶/底背离。背离需两个价格摆点，每个摆点等待右侧两根确认，标在确认日；盘中只预警。VOL相对此前20根均量标注放量/缩量及方向；当日未完成时不标全天缩量。标签独立于价格缩放，同屏限制密度，全量细节保留在分析结果中。

## 使用云同步

网页与iOS“设置 → 自选云同步”创建同步，复制密钥到另一设备选择“连接并合并自选”。无需另配第三方服务。密钥拥有者可读写该份自选，应只交给自己的设备，不能贴进公开分享链接。密钥不作为URL参数发送，服务端按其SHA-256派生独立Durable Object地址；本地保留密钥，服务端保存自选/分组与修订版本。

前台每30秒与增删后的合并请求仅同步自选资料，不扫描行情；离线修改保留并补传。使用相对上次确认快照的增删操作合并，防止另一台设备未变的旧名单复活已删除股票。不同分组与同组的独立成员增删可合并，同一字段的冲突按后到操作生效。重复传输幂等。断开只清除本设备同步密钥，不删除本机或云端名单。显示设置、提醒、收藏与交易账户不参与同步。

## 旧域名恢复

新站首次启动或设置中的“恢复旧站自选”进入旧域名的同一浏览器本地存储，合并旧自选和新站新增自选/分组。端到端AES-GCM临时密文只保留10分钟，密钥在返回fragment中随后删除；不迁移授权令牌。旧站数据保留。浏览器原站点数据已被清理或使用另一浏览器时，无法读取原本地存储，应从仍保留数据的设备建立云同步。
